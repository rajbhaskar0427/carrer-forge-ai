### Reverse-engineer your dream career.

🔗 **Live Demo:** https://carrer-forge-ai-coral.vercel.app/

## 💡 About the Project

CareerForge AI is an AI-powered career roadmap platform designed to solve a common problem faced by college students: **generic career advice**.

Instead of simply telling students to "learn React" or "build projects", CareerForge works backwards from a user's **specific dream role** and generates a personalized roadmap showing the skills, projects, credentials, experience, and realistic career stepping stones required to reach that destination.

> **Don't guess your career. Reverse-engineer it.**

---

## 🎯 Problem Statement

Traditional career advice is often too generic.

For example, a student interested in becoming a:

> **Frontend Engineer at a product-based fintech startup**

might simply be told:

- Learn HTML
- Learn CSS
- Learn JavaScript
- Learn React
- Build a portfolio

But real career journeys are more nuanced.

Students need to understand:

- What skills are actually required?
- Which skills are they currently missing?
- Which projects demonstrate those skills?
- What intermediate roles should they target?
- Which credentials can strengthen their profile?
- What experience should they gain before applying?
- What should they focus on **next**?

CareerForge addresses this gap by transforming a dream role into an actionable, personalized career strategy.

---

## 🧠 Our Solution

CareerForge uses a **reverse-engineering approach** to career planning.

### User Input

The user provides:

- 🎯 Dream role
- 🏢 Target company / industry
- 📚 Current skills
- 👨‍💻 Experience level
- ⏱️ Weekly learning capacity
- 📅 Target timeline



The platform analyzes the target career and maps:

**Required Skills → Skill Gaps → Projects → Credentials → Experience → Intermediate Roles → Dream Role**

### Personalized Output

The user receives an interactive roadmap containing:

- Career phases
- Skill-gap analysis
- Recommended projects
- Career milestones
- Realistic stepping-stone roles
- Progress tracking
- AI-powered recommendations
